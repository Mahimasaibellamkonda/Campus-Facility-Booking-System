CampusFlow – Campus Facility Booking System

CampusFlow is a web-based Campus Facility Booking System developed using HTML, CSS, and basic JavaScript.

The system allows students and staff to reserve campus facilities such as seminar halls, computer labs, conference rooms, auditoriums, sports halls, and project labs.

---

 Project Objective

The main objective of this project is to provide a simple digital platform for managing campus facility reservations.

Instead of manually checking facility availability and maintaining paper-based booking records, users can enter their booking details through the website and view existing reservations.

---

 Features

 Facility Booking

Users can book a facility by providing:

- Student / Staff name
- Facility
- Date
- Time slot
- Number of participants
- Purpose
- Additional notes

Search

Users can search booking records using:

- Booking ID
- Name
- Facility
- Purpose

 Facility Filter

Bookings can be filtered according to the selected facility.

 Duplicate Booking Prevention

The system checks whether the same facility has already been booked for the selected date and time.

If a duplicate booking exists, the system prevents the new booking.

 Cancel Booking

Users can cancel an existing booking from the booking records section.

 Dashboard Statistics

The dashboard displays:

- Today's bookings
- Total bookings
- Number of available facilities

 Local Storage

Booking information is stored using the browser's "localStorage".

Therefore, the booking records remain available even after refreshing the page.

 Responsive Design

The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices
